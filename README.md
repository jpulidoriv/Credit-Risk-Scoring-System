# Credit Risk Scoring System
## Project Overview
This project builds a credit risk scoring system to estimate the probability that a loan applicant will experience payment difficulties or default. The goal is not only to predict default, but also to transform model outputs into business-oriented risk decisions.

The system uses historical loan application data, customer characteristics, credit history, and previous payment behavior to train a binary classification model. The predicted probability of default is then used to assign each applicant to a risk band and estimate the expected loss of the loan.

The project combines SQL-based feature engineering, Python data analysis, machine learning classification, model evaluation, and credit risk business logic.
